FAQ

Frequently Asked Questions

How does FlowLock handle cyclic dependencies?

FlowLock runs graph validation algorithms in real-time. If you attempt to connect Task A to Task B when B already depends on A, the system immediately rejects the link with an error warning.

Can I override a locked task in emergency situations?

Yes. Project administrators have permissions to force-unlock tasks or bypass dependency rules, with all override actions logged for audit history.

Does FlowLock integrate with GitHub and Jira?

Absolutely. You can link pull requests and Jira issues directly to FlowLock nodes to automatically move task statuses when PRs are merged.
